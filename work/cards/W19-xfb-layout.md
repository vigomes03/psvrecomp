# W19 — Read the transform feedback layout from the NVN shader control section (pure function + test)

## Context
Each NVN vertex shader comes with a "control section" (bytes generated by the glslc compiler). When the shader uses
transform feedback (the GPU writes the vertex shader outputs to buffers), the layout is in this section. Claude discovered
the fields by comparing the 1009 vertex shaders of the game (28 use transform feedback). All integers are little-endian.

| offset | type | meaning |
|---|---|---|
| `0x6ED` | u8 | 1 = transform feedback enabled; 0 = disabled (nothing else matters) |
| `0x6EC` | u8 | number of buffers used (1 to 4) |
| `0x6E8 + b` | u8 | 1 = buffer `b` active (b = 0..3) |
| `0x6DC + 2*b` | u16 | stride of buffer `b` in bytes |
| `0xDC + 0x80*b` | u8 | output captured by buffer `b`: `0x20` = output 0 (v0), `0x21` = output 1 (v1), ... |
| `0x4DC + 0x80*b` | u8 | how many components (1 to 4, starting from .x) of the output buffer `b` captures |

## Deliverables: two files
1. `xfb_layout.c` (only `<stdint.h>` and `<string.h>`), with:
```c
typedef struct {
    uint8_t enabled;       // 0 or 1
    uint8_t nbuf;          // value of 0x6EC
    struct {
        uint8_t active;    // 0x6E8 + b
        uint16_t stride;   // 0x6DC + 2*b
        uint8_t output;    // (byte at 0xDC + 0x80*b) - 0x20; 0xFF if the byte is < 0x20
        uint8_t ncomp;     // 0x4DC + 0x80*b
    } buf[4];
} XfbLayout;
// control: pointer to the control section (at least 0x700 bytes).
// Disabled: zero out *out and return 0. Enabled: fill the 4 buffers (inactive ones remain all 0) and return nbuf.
// Returns -1 (and zeroes out *out) if enabled but something is invalid: nbuf outside 1..4, active buffer with stride 0,
// ncomp outside 1..4, output 0xFF, or stride < 4*ncomp.
int xfb_layout_parse(const uint8_t *control, XfbLayout *out);
```
Read u16 with `memcpy` (do not cast misaligned pointer).

2. `test_xfb.c` with `main(int argc, char **argv)`: `argv[1]` is the folder with the sample .bin files. For each case below,
read the whole file (`fopen`/`fread`, mode `"rb"`), call `xfb_layout_parse`, and check. Print `PASS n` or
`FAIL <file> <field>` and return 0 only if everything passes. One more case without a file: a zeroed 0x700-byte buffer,
with `[0x6ED]=1`, `[0x6EC]=1`, `[0x6E8]=1`, stride 0 → must return -1.

| file | return | active buffers: (stride, output, ncomp) |
|---|---|---|
| `76e62e9c00.bin` | 0 | none (enabled 0) |
| `7442108000.bin` | 1 | b0 (12, 0, 3) |
| `74420fe000.bin` | 1 | b0 (12, 0, 3) |
| `74420fe600.bin` | 2 | b0 (12, 0, 3), b1 (4, 1, 1) |
| `74420fee00.bin` | 3 | b0 (12, 0, 3), b1 (4, 1, 1), b2 (4, 2, 1) |
| `7442120000.bin` | 3 | b0 (12, 0, 3), b1 (12, 1, 3), b2 (12, 2, 3) |

Buffers not listed must have active 0, stride 0, output 0, ncomp 0.
