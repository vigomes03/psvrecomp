# Phase 1: ARM64 → C recompiler

**Goal:** turn `main` + `sdk` (+ `subsdk*`) into C that compiles into a DLL, with semantics proven by
differential tests.

**In Zelda:** `nso.py` → `gen.py` (fixed-point function discovery, jump tables via Unicorn, emission with `goto`
/ `musttail` / `rt_dispatch`) → `lifter.py` (integers/memory/control) + `simd_c.py` (FP/SIMD in portable C) →
chunks of ~1,500 functions → `clang -O1`. Tests: `test_lift.py`, `test_simd.py`.

## Risks
- Compilation: millions of lines of C. Mitigation: `-O1`, balanced chunks (LAS already does this), ccache, compiling in batches.
- Code generated by a different compiler (Game Freak uses the same clang as the SDK, so patterns similar to LAS).
